# **A500Sub — Amiga A500+ Rev 8A.2 (KiCad Reconstruction)**

A full KiCad reconstruction of the **Commodore Amiga A500+ Rev 8A.2** motherboard, supported with a complete BOM, 3D models, and reference images.  
This project preserves the A500+ Rev 8A.2 board layout in an editable, open format for restoration, repair, and hardware exploration.

---

## 🧭 Project Purpose

The goal of this repository is to provide a clean, accurate, and reproducible version of the **A500+ Rev 8A.2** motherboard for:

- Restoring original A500+ systems  
- Building new boards from scratch  
- Hardware repair and diagnostics  
- Long‑term preservation of Commodore’s design  
- Modding, expansion, and experimentation  

All Gerbers and KiCad sources are included for manufacturing and study.

---

## 🛠️ Features

### **✔️ Complete KiCad Reconstruction**
- Editable PCB layout  
- Accurate trace routing  
- Includes footprints, netlist, and 3D models  
- Suitable for fabrication without modification  

### **✔️ Manufacturing‑Ready Gerbers**
- Clean, validated Gerber set  
- Provided both in the `/gerbers` folder and as a ZIP archive  

### **✔️ Full BOM Included**
- Component list for building the board  
- Helps with sourcing legacy and modern‑equivalent parts  

### **✔️ 3D Models & Renders**
- Visual reference for assembly  
- Useful for verifying component placement and clearances  

---

## 🧩 About the Amiga A500+ Rev 8A.2

The **A500+** was the final revision of the classic Amiga 500 line, featuring:

- ECS chipset  
- 1 MB Chip RAM  
- Battery‑backed RTC  
- Updated motherboard layout  
- Improved memory and expansion handling  

Rev 8A.2 is one of the later, more stable board revisions, making it ideal for restoration and reproduction.
